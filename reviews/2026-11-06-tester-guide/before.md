# WowVision 한국어 테스트 설치 안내

`WowVisionInstaller.exe` 하나만 실행하면 됩니다. 원본 WowVision 설치 프로그램 1.6과 같고, 두 가지만 더했습니다. 화면 문구에 한국어를 넣었고, 설치가 끝날 때마다 WowVision에 한국어 문자열을 덮어씁니다.

## 먼저 확인할 것

- 게임 클라이언트가 한국어여야 합니다. WowVision은 게임 클라이언트의 언어를 보고 문구 언어를 고릅니다. 클라이언트가 영어이면 영어로 나옵니다.
- 설치하는 동안 World of Warcraft를 완전히 종료하십시오.

## 설치

`WowVisionInstaller.exe`를 실행합니다. Windows 표시 언어가 한국어이면 처음부터 한국어로 나옵니다. 아니면 구성 요소 화면의 "이 설치 프로그램의 언어"에서 한국어를 고릅니다.

첫 화면에는 설치 방법이 둘 있습니다.

- "지금 설치" 또는 "지금 업데이트": 찾아낸 게임 버전에 권장 설정으로 바로 설치합니다. 이 방법으로는 NVDA 음성 브리지와 Windows 음성 복사가 설치되지 않습니다.
- "WowVision 새로 설치, 또는 다른 게임 버전에 설치": 게임 버전, 폴더, 구성 요소를 직접 고릅니다. NVDA로 게임 음성을 듣고 싶으면 이쪽을 고르십시오.

### 직접 고르기

"WowVision 새로 설치, 또는 다른 게임 버전에 설치"는 세 페이지로 이어집니다. "다음"으로 넘어가고 "뒤로"로 돌아갑니다.

1. 게임 버전: 플레이하는 버전을 모두 체크합니다.
2. 폴더: 버전마다 WowVision을 설치할 폴더입니다. 틀렸거나 비어 있으면 옆의 "찾아보기"로 고릅니다.
3. 구성 요소: 기본값이 권장 설정입니다. 이 페이지에는 다음 항목이 있습니다.
   - 이 설치 프로그램의 언어
   - 설치할 WowVision: 안정판(권장) 또는 베타
   - 추가 권장 애드온: Pawn을 뺀 나머지가 체크되어 있습니다.
   - WowVision Updater의 바탕 화면 바로 가기 만들기 (체크됨)
   - WoW에서 NVDA를 음성으로 사용 (체크 안 됨): NVDA 음성 브리지를 설치해서, 게임의 음성 목록에 NVDA가 나타나고 WowVision이 NVDA로 말하게 합니다.
   - 모든 Windows 음성을 WoW에서 사용 (체크 안 됨): 게임이 보지 못하는 새 Windows 음성을 게임의 음성 목록에 복사합니다. 게임의 음성 번호가 바뀔 수 있으니 설치 뒤 음성 설정을 확인하십시오.
   - WoW Login Tool 설치(권장) (체크됨)
   - 모두 다시 설치(복구) (체크 안 됨): 설치가 손상되었을 때 씁니다.

"설치"를 누르면 설치가 시작됩니다. 음성 옵션 두 가지는 컴퓨터 전체의 음성 목록을 바꾸기 때문에 기본으로 꺼져 있고, "지금 업데이트"는 이 옵션들을 실행하지 않습니다. 나중에 음성 옵션을 켜려면 다시 "WowVision 새로 설치, 또는 다른 게임 버전에 설치"를 고르십시오.

설치가 끝나면 Battle.net에서 게임을 시작합니다.

## 그 뒤에 알아 둘 것

- WowVision 업데이트도 이 설치 프로그램으로 하십시오. 업데이트하면 WowVision 폴더가 원본으로 바뀌지만, 이 설치 프로그램은 실행할 때마다 한국어를 다시 넣습니다.
- 설치 프로그램이 자체 업데이트를 권하면 "현재 버전으로 계속"을 고르십시오. 업데이트하면 한국어가 없는 원본 설치 프로그램으로 바뀌고, 그 뒤로 WowVision을 업데이트할 때 한국어가 빠집니다.
- 새 테스트용 설치 프로그램을 받으면 이전 것 대신 새 것을 실행합니다.
- 한국어를 넣지 못하면 진행 화면에 "한국어 문구를 추가하지 못했습니다"라고 나옵니다. 그때 WowVision은 영어로 동작합니다. 아래 방법으로 로그를 보내 주십시오.
- 문제가 생기면 설치 프로그램 첫 화면의 "모든 로그 모으기"로 만든 zip 파일을 보내 주십시오. 다운로드 폴더에 저장됩니다.
