# 번역 검수 기록

WowVision 한국어판의 번역 검수 회차별 기록입니다. 검수 방식(평가자 구성, 반박, 두 회사 판정, 회귀 확인)은 `docs/review-process.md`에 있습니다. 이 폴더에는 회차마다 무엇을 검수했고 무엇이 바뀌었는지만 남깁니다.

## 원본 파일 꺼내기

2026-11-19에 평가자 입력·출력 같은 중간 파일 5,468개(약 95MB)를 최신본에서 지웠습니다. 지운 파일은 커밋 `8be41d2`에 모두 남아 있습니다. 문서가 이 폴더의 회차나 파일을 근거로 가리키는데 최신본에 없으면, 그 커밋에서 꺼냅니다.

    git checkout 8be41d2 -- reviews/2026-11-05-manual

최신본에 남긴 파일은 다음과 같습니다.

- 사람이 읽는 기록: 모든 `.md`(보고서, 메모), `.tsv`(반영 목록, 사용자 결정), `.txt`(바뀐 내용, 채점 결과)

중간 파일만 있던 회차는 폴더째 최신본에서 빠졌습니다. 그런 회차도 아래 회차 목록에는 있습니다.
- 현행 문서가 파일 단위로 인용하는 JSON 4개: `2026-11-05-manual/escalations.json`, `2026-11-05-manual-regression/upstream-raw.json`, `2026-11-06-final-ui/result.json`, `2026-11-09-ui-main-merge/batch-01/gpt-terminology-recheck.json`
- 대표 사례 2개(아래 `## 대표 사례`)

## 대표 사례

한 회차가 처음부터 끝까지 어떻게 흘러가는지 보려면 다음 두 곳을 엽니다.

- UI 문자열: `2026-11-14-ui-v1.0.3/` 전체. `batches/`(평가 묶음) → `batch-01/`(Claude·GPT 평가자가 관점별로 낸 지적, 번역자의 `rebut.json`) → `full-result.json`(판정 결과) → `apply.tsv`(반영 목록) → `regression-1/`(회귀 확인). `vessel-*`은 배·비행선 이름을 따로 돌린 묶음으로, 두 회사 판정자(`judge-*`)까지 거친 예입니다.
- 설명서: `2026-11-14-manual-v1.0.3/reference/keybindings/`. 관점별 평가자 입력(`*-input-*`)과 출력, 번역자 반박(`rebut.json`), 두 회사 판정(`judge-*`, `judged.json`), 수정(`fix.json`) 순서입니다. 같은 쪽의 회귀 확인은 `regression-1/reference/keybindings/`에 있고, 회차 전체 결과는 `manual-result.json`입니다.
