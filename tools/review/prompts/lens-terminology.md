# 관점: 용어 (category = terminology)

용어 선택만 본다.

- `game_term`이 있는데 따르지 않았거나, 후보 중 문맥에 맞지 않는 것을 고른 경우
- 게임 용어(창 이름, 직업, 자원, 역할, 아이템 품질, 경매·길드·파티 용어)를 공식 한국어가 아닌 말로 옮긴 경우. 판단이 필요하면 `cache/gs_enUS.csv`와 `cache/gs_koKR.csv`(작업 폴더 `wowwork` 아래, BaseTag로 대조)를 직접 검색해도 된다
- 같은 영어 용어가 이 묶음이나 `wowvision-ko/vision-locale/koKR/*.lua`의 다른 번역과 다르게 옮겨진 경우(일관성). 검색해서 확인한다
- 고유 이름·키 이름을 번역해 버린 경우
