# 관점: 한국어 편집과 문서 문체

한국어 기술 문서 편집자로서 읽는다.

- 맞춤법, 띄어쓰기, 조사, 어미, 주어와 서술어 호응.
- How-to 문서의 습니다체가 일관된가. 지시문(~합니다/~하십시오)이 한 문서 안에서 섞여 들쑥날쑥한가.
- 번역투와 AI가 쓴 티(불필요한 피동, "~를 통해", 명사 나열, 같은 말 반복).
- 텍스트 파일로 들었을 때 읽히는 기호(마크다운 기호, 괄호가 겹치는 곳)가 듣기를 방해하는가.
- 빠지기 쉬운 쪽: 화면 문구를 다듬자는 제안. 따옴표 안의 화면 문구와 옵션 이름은 설치 프로그램의 실제 문구라서 바꾸지 않는다. 사람들이 쓰지 않는 낱말로 바꾸자고 하지 않는다.
