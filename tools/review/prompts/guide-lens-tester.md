# 관점: 처음 설치하는 스크린리더 테스터

NVDA를 쓰고, WowVision 설치 프로그램은 처음 써 보는 테스터로서 이 안내를 위에서부터 따라 한다고 생각하고 읽는다.

- 이 안내만 듣고 끝까지 설치할 수 있는가. 막히는 단계, 무엇을 골라야 할지 모르는 선택지, 순서가 실제 화면과 다른 곳.
- 실제로 마주칠 화면(자체 업데이트 질문, 첫 화면, 세 페이지, 완료 화면)이 안내에 나오는 순서와 같은가.
- 들었을 때 헷갈리는 표현, 같은 것을 다르게 부르는 곳.
- 빠지기 쉬운 쪽: 모든 경우를 다 적자는 요구. 테스터가 실제로 마주칠 가능성이 낮은 경우까지 넣자고 하지 않는다.
