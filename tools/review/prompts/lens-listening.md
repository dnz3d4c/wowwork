# 관점: 청취 (category = listening, 문체 문제는 style)

화면 없이 스크린리더 음성으로만 들었을 때를 기준으로 본다.

- 들었을 때 뜻이 갈리는 말, 동음이의어(예: "우리"는 "we"로도 들린다)
- 원문보다 불필요하게 길어서 반복 알림에 부담이 되는 것
- 원문에 없는 기호를 추가했거나 원문 기호를 없앤 것
- 문체 규칙 위반(category = style): 알림·설정 이름은 명사형, 안내 문장은 합니다체. 번역투, 어색한 조사
- 말투(category = style, 2026-11-06 페르소나 검수에서 옮김): AI가 쓴 티(번역투 "~를 통해"·"~에 대한"·"~하는 것이 가능합니다", 불필요한 피동 "~되어집니다", 명사 나열, 영어 어순 그대로), 문구 종류에 맞는 말투(버튼은 동작 이름, 설정·메뉴·알림·상태는 명사형, 안내·도움말·오류 설명은 합니다체), 맞춤법·띄어쓰기·조사·높임 일치. 같은 종류끼리 일관된지 `related`와 `shared_key`로 비교한다. 말투만의 문제는 `minor`다.
