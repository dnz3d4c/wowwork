# 관점: 회귀 확인

입력의 `after`는 평가, 작성자 반박, 두 회사 판정을 거쳐 방금 고친 안내다. 관점 하나가 아니라 위의 세 관점(처음 설치하는 테스터, 사실 검증, 한국어 편집)을 모두 적용해 처음부터 다시 평가한다.

추가로 확인한다.

- 고치면서 새로 생긴 잘못: 앞뒤 단계가 맞지 않음, 같은 것을 다르게 부름, 사실과 다른 문장.
- 따옴표 규칙: 큰따옴표는 설치 프로그램의 실제 화면 문구(Ko 표, 영어 화면 이름은 En 표)에만 쓰고, 안내 안의 절 이름은 작은따옴표로 가리킨다.
- 이미 판정을 거쳐 유지하기로 한 것: "다음", "뒤로"는 방향 기호 없이 인용한다(두 회사 판정). 이것은 다시 지적하지 않는다.

통과 기준은 critical·major 0건이다. minor는 보고만 한다.
