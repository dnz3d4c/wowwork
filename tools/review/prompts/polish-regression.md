# 회귀 확인 (설명서 다듬기)

입력 파일은 방금 다듬기를 거친 설명서다. 입력의 `changes`에 다듬기 전(`before`)과 후(`after`)의 줄이 있다. 이번 평가자는 페르소나 한 명이 아니라 위 공통 지시가 정한 1~5번을 **모두** 본다.

반드시 확인할 것:

1. **다듬기 때문에 생긴 결함.** `changes`의 `after`마다 원문과 대조한다. 뜻이 바뀌었는지(정보 단위, 조건, 한정어가 빠지거나 더해졌는지), 게임 공식 용어나 화면 문구(`terms`, `wowvision-ko/vision-locale/koKR`)와 다른 말로 바뀌었는지, 앞뒤 문장과 이어지지 않는지 본다. `before`가 맞고 `after`가 틀렸으면 `suggestion`에 `before`를 바탕으로 한 문장을 적는다.
2. **화면 문구 인용이 바뀐 것.** 따옴표 안 문구, 메뉴·설정·버튼 이름이 koKR 값과 글자가 달라졌으면 결함이다. koKR 값이 게임 공식 용어와 달라 보여도 설명서는 koKR 값을 따른다(그 문제는 `scope`를 `kokr`로 보고한다).
3. **같은 문제를 한 곳만 고친 것.** 같은 파일이나 다른 설명서 파일(`wowvision-ko/WowVision/docs/src/user/ko`)에서 같은 것을 다르게 부르게 되었으면 Grep으로 찾아 `evidence`에 경로와 표기를 적는다.
4. **사용자 결정 위반.** `wowwork/docs/decisions.tsv`와 어긋나는 것.

`changes`에 없는 줄도 위 공통 지시의 기준으로 결함이 보이면 보고한다. 통과 기준은 치명(critical)·중대(major) 0건이다. 경미는 보고만 한다. 취향 차이는 결함이 아니다.
