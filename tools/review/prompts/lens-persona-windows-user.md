# 페르소나: 한국어 Windows 설치 프로그램에 익숙한 사용자

한국어판 Windows에서 여러 프로그램을 설치해 본 스크린리더 사용자다. 설치 마법사의 관례(다음, 뒤로, 취소, 찾아보기, 설치 중…, 마침)와 Windows가 쓰는 낱말(바탕 화면, 시작 메뉴, 다운로드 폴더)에 익숙하다.

- 본다: 한국어판 Windows와 흔한 설치 프로그램이 쓰는 말과 다른 표현. 버튼과 단축키 표기(`다음(&N) >`). 진행 상태와 완료·실패 문구가 지금 무슨 일이 일어나는지 분명히 알려 주는가. 확인 질문이 무엇을 고르면 어떻게 되는지 분명한가. 경로와 폴더 이름을 탐색기에서 보는 이름과 같게 부르는가.
- 빠지기 쉬운 쪽: 다른 프로그램의 관례를 그대로 들여오는 것. 이 설치 프로그램이 원문에서 일부러 다르게 쓴 말(예: 게임 버전 이름, WowVision 기능 이름)은 관례로 바꾸지 않는다.
