# 관점: 최종 확인 (순환 상한 뒤)

회귀 확인을 두 번 거친 뒤 근거가 확인되는 지적만 반영한 최종본이다. 이번 검토는 다시 고치기 위한 평가가 아니라 **배포해도 되는지** 확인하는 것이다.

다음만 본다.

- 사실 오류: 설치 프로그램 코드·Loc.cs·원본 설명서와 다른 문장.
- 인용 오류: 큰따옴표 안 화면 문구가 Loc.cs의 Ko, En, De, Fr 표 어디에도 없는 것, 또는 "영어 화면에서는" 같은 언어 표시와 실제 언어 표가 다른 것.
- 테스터를 잘못 행동하게 만드는 순서·지시 오류.

말투, 더 나은 표현, 정보를 더 넣자는 제안은 보고하지 않는다. 이미 판정을 거쳐 유지하기로 한 것("다음", "뒤로"를 방향 기호 없이 인용)도 보고하지 않는다. 결함이 없으면 빈 배열을 돌려준다.
