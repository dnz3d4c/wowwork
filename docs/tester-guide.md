WowVision 한국어판 테스트 설치 안내

테스터용 안내입니다. WowVisionInstaller.exe를 실행해 설치하고, 업데이트도 같은 파일로 진행합니다. 이 설치 프로그램은 원본 WowVision 설치 프로그램 1.6을 바탕으로 합니다. 화면 문구를 한국어로 보여 주고, 설치나 업데이트를 마칠 때마다 WowVision에 한국어 문구를 덮어쓰며, 한국어 음성 팩(Yuna)와 NVDA 음성 브리지를 기본으로 설치합니다. 이 브리지로 센스 리더에도 말할 수 있습니다.

한국어 설명서: https://dnz3d4c.github.io/WowVision/user/ko/getting-started/introduction.html


시작하기 전에

- 게임 클라이언트 언어가 한국어여야 WowVision이 한국어로 말합니다. 클라이언트가 영어이면 영어로 말합니다.
- World of Warcraft를 완전히 종료합니다.
- 이 안내는 설치 프로그램 화면이 한국어로 나오는 경우를 기준으로 합니다. 설치 프로그램은 Windows 표시 언어를 따르므로, Windows 표시 언어가 한국어가 아니면 다른 언어로 나옵니다. 이때는 아래 '직접 선택'의 구성 요소 페이지에서 설치 프로그램의 언어를 한국어로 변경할 수 있습니다.


설치하기

1. WowVisionInstaller.exe를 실행합니다. Windows가 이 앱이 디바이스를 변경하도록 허용할지 물으면 '예' 버튼을 실행합니다. 설치 프로그램이 게임 폴더에 파일을 써야 해서 이 허용이 필요합니다. Windows가 인식할 수 없는 앱이라고 경고하면 '추가 정보' 링크를 실행한 뒤 '실행' 버튼을 실행합니다.
2. 설치 프로그램 자체의 업데이트를 알리는 화면("설치 프로그램 자체의 업데이트가 있습니다")이 나오면 "현재 버전으로 계속" 버튼을 실행합니다. "설치 프로그램을 지금 업데이트 (권장)" 버튼을 실행하면 한국어가 없는 원본 설치 프로그램으로 변경되고, 그 뒤로는 WowVision을 업데이트할 때 한국어가 빠집니다.
3. 첫 화면에서 설치 방법을 선택합니다. 첫 화면의 버튼은 WowVision이 설치되어 있는지에 따라 다릅니다.
   - "권장 구성으로 설치" 버튼: WowVision이 설치되어 있지 않을 때 나옵니다. 컴퓨터에서 찾은 게임 버전에 설치합니다.
   - "현재 설정으로 업데이트" 버튼: WowVision이 이미 설치되어 있을 때 나옵니다. 설치된 게임 버전을 업데이트하며, 안정판·베타와 추가 권장 애드온은 지난번 선택을 따릅니다.
   - "WowVision 새로 설치, 또는 다른 게임 버전에 설치" 버튼: 게임 버전, 폴더, 구성 요소를 직접 선택합니다. 아래 '직접 선택'을 따른 뒤 4단계로 돌아옵니다.
   - 게임을 찾지 못하면 "설치된 World of Warcraft를 찾지 못함"이 나오고, 설치 버튼 대신 "찾아보기" 버튼이 나옵니다. "찾아보기" 버튼을 실행해 World of Warcraft 폴더, 게임 버전 폴더(예: _retail_), 또는 게임 버전 폴더 안의 Interface\AddOns 폴더를 선택한 뒤 설치 방법을 선택합니다.
4. 설치가 끝나면 "완료" 또는 "문제가 있었지만 완료"가 나옵니다.
   - "완료"이면 "설치 프로그램 닫기" 버튼을 실행합니다.
   - "문제가 있었지만 완료"이면 결과 요약에서 어느 게임 버전에서 무엇이 실패했는지 확인합니다. 단계별 내용은 "진행 기록 보기" 버튼을 실행하면 볼 수 있습니다. 설치 프로그램을 닫은 뒤 아래 '문제가 생기면'에 따라 로그를 보내 주십시오.
5. Battle.net에서 게임을 시작합니다.


직접 선택

"WowVision 새로 설치, 또는 다른 게임 버전에 설치" 버튼을 실행하면 세 페이지가 차례로 나옵니다. "다음" 버튼을 실행하면 다음 페이지로 넘어가고, "뒤로" 버튼을 실행하면 이전 페이지로 돌아갑니다.

1. 게임 버전: 플레이하는 버전을 모두 체크합니다.
2. 폴더: 버전마다 WowVision을 설치할 폴더입니다. 틀렸거나 비어 있으면 옆의 "찾아보기" 버튼을 실행해 선택합니다.
3. 구성 요소: 기본값이 권장 구성이므로, 변경할 것이 없으면 "설치" 버튼을 실행합니다. 이 페이지의 항목은 다음과 같습니다.
   - 이 설치 프로그램의 언어: 여기서 한국어를 선택할 수 있습니다.
   - 설치할 WowVision: 안정판(권장) 또는 베타를 선택합니다. 원본과 같이 안정판이 미리 선택되어 있습니다. 다만 전에 이 페이지에서 베타로 변경한 적이 있으면 베타가 그대로 선택되어 있으므로, 안정판으로 변경해 주십시오.
   - 추가 권장 애드온: Pawn을 뺀 나머지가 기본으로 체크되어 있습니다.
   - WowVision Updater의 바탕 화면 바로 가기 만들기: 기본으로 체크되어 있습니다. 바로 가기가 만들어져도 업데이트에는 사용하지 않습니다(아래 '업데이트' 참고).
   - WoW에서 NVDA를 음성으로 사용: 기본으로 체크되어 있습니다(한국어판에서 변경). NVDA 음성 브리지를 설치합니다. 그러면 게임의 음성 목록에 NVDA가 나타나고 WowVision이 NVDA로 말할 수 있습니다. 한국어판은 이 브리지로 센스 리더에도 말할 수 있습니다(아래 '센스 리더로 듣기' 참고).
   - 모든 Windows 음성을 WoW에서 사용: 기본으로 체크되어 있지 않습니다. 게임이 인식하지 못하는 새 Windows 음성을 게임의 음성 목록에 복사합니다. 게임의 음성 번호가 바뀔 수 있으니 설치 뒤 WowVision의 음성 설정을 확인합니다.
   - WoW Login Tool 설치(권장): 기본으로 체크되어 있습니다. 한국어판은 원본 로그인 툴을 설치한 뒤 한국어 파일을 덮어씁니다. 로그인 툴을 처음 실행하면 나오는 설정에서 언어는 한국어, 지역은 한국을 선택합니다.
   - 모두 다시 설치(복구): 기본으로 체크되어 있지 않습니다. 설치가 손상되었을 때 사용합니다.

음성 옵션 두 가지는 컴퓨터 전체의 음성 목록을 변경합니다. 원본은 둘 다 기본으로 꺼 두지만, 한국어판은 NVDA 음성 브리지를 기본으로 설치합니다. "권장 구성으로 설치"와 "현재 설정으로 업데이트"는 이 기본값으로 진행하므로 항상 브리지를 설치합니다. 브리지를 설치하지 않으려면 "WowVision 새로 설치, 또는 다른 게임 버전에 설치" 버튼을 실행하고 구성 요소 페이지에서 체크를 해제합니다. Windows 음성 복사는 원본처럼 꺼져 있고 "현재 설정으로 업데이트"로는 켜지지 않습니다. 필요하면 같은 버튼을 실행해 구성 요소 페이지에서 체크합니다.


센스 리더로 듣기

한국어판에만 있는 기능입니다. NVDA 음성 브리지를 설치하면 WowVision이 센스 리더로도 말합니다. 원본 브리지는 NVDA로만 말합니다.

1. 위 구성 요소 페이지에서 "WoW에서 NVDA를 음성으로 사용"을 체크한 채로 설치합니다. 기본값이므로 "권장 구성으로 설치"와 "현재 설정으로 업데이트"도 이 기능을 설치합니다.
2. WoW를 종료한 상태에서 설치합니다. WoW가 실행 중이면 브리지 파일을 바꿀 수 없어서, 설치 프로그램이 센스 리더 연결을 추가하지 못했다고 알립니다. 그때는 WoW를 종료하고 설치 프로그램을 다시 실행합니다.
3. WowVision 메뉴(Shift+F1)의 음성 항목에서 음성 종류를 SAPI2SR로 선택합니다. NVDA 사용자와 같은 음성입니다.
4. NVDA를 끄고 센스 리더를 실행한 상태로 게임을 합니다.

말할 곳은 말할 때마다 정합니다. NVDA가 실행 중이면 NVDA로 말하고, NVDA가 꺼져 있고 센스 리더가 실행 중이면 센스 리더로 말합니다. 그래서 게임 도중에 NVDA와 센스 리더를 바꿔 실행해도 됩니다. 둘 다 실행 중이면 NVDA로만 말합니다.

- 앞의 말을 끊고 새 말을 하는 동작과 음량 0인 부분을 읽지 않는 동작은 NVDA와 같습니다.
- 점자 출력은 NVDA로만 보냅니다. 센스 리더로 말한 내용은 NVDA 브리지의 말한 내용 기록에 남지 않습니다.
- 원본 WowVision 설치 프로그램이나 Sku 설치 프로그램을 실행하면 브리지가 원본 상태로 돌아가 센스 리더로 말하지 않습니다. 그때는 이 설치 프로그램을 다시 실행합니다.


업데이트

- WowVision을 업데이트할 때도 받은 WowVisionInstaller.exe를 실행합니다. 바탕 화면과 시작 메뉴의 WowVision Updater 바로 가기는 사용하지 않습니다. 바로 가기는 정해진 위치에 복사해 둔 설치 프로그램을 실행하는데, 이 복사본이 원본 설치 프로그램의 더 새 버전이면 한국어판을 실행해도 변경되지 않아 한국어가 빠질 수 있습니다.
- 업데이트하면 WowVision 폴더가 원본으로 바뀌지만, 이 설치 프로그램은 업데이트를 마칠 때마다 한국어 문구를 다시 덮어씁니다.
- 새 테스트용 설치 프로그램을 받으면 이전 파일 대신 새 파일을 실행합니다.


한국어 음성 팩(Yuna)

일부 알림은 TTS 대신 녹음된 음성 팩으로 재생합니다. 처음부터 녹음으로 나오는 알림은 나침반 방향과 대상까지 거리의 숫자입니다. 대상 생명력과 적의 수는 처음에는 TTS로 읽고, 설정을 변경하면 녹음된 숫자로 들을 수 있습니다.

원본에는 영어 음성 팩 Matthew와 Joanna만 있습니다. 이 설치 프로그램은 한국어 음성 팩 Yuna를 함께 설치합니다. Yuna에는 여덟 방향과 1부터 100까지의 숫자가 포함되어 있고, 업데이트할 때마다 다시 설치됩니다.

기본 음성 팩은 원본처럼 Matthew라서, 그대로 두면 나침반 방향과 숫자가 영어로 들립니다. 캐릭터가 월드에 들어간 뒤, 한국어로 들을 알림마다 음성 팩을 Yuna로 변경합니다. 나침반 예:

1. Shift+F1을 눌러 WowVision 메뉴를 엽니다. 길 안내 버튼으로 이동해 Enter를 누르고, 이어서 나침반 버튼으로 이동해 Enter를 누릅니다.
2. 나침반 방향 읽기 버튼으로 이동해 Enter를 누르고, 이어서 음성 팩 알림 버튼으로 이동해 Enter를 누릅니다.
3. 음성 팩 드롭다운에서 Enter를 눌러 목록을 열고, Yuna로 이동해 Enter를 누릅니다. '음성 팩, 드롭다운, Yuna'가 들리면 변경이 끝났습니다.
4. Escape를 누를 때마다 한 단계씩 돌아가고, 첫 단계에서 누르면 메뉴가 닫힙니다.

대상까지 거리는 목표 선택 버튼, 하드 대상 버튼, 거리 변경 버튼 순서로 들어가 2단계의 음성 팩 알림 버튼부터 같은 방법으로 변경합니다.

대상 생명력과 적의 수는 음성 팩 알림이 처음에 꺼져 있습니다. 녹음으로 들으려면 음성 팩 알림 버튼에서 Enter를 누르고, 사용함 체크 상자에서 Enter를 눌러 체크됨으로 바꾼 다음, 음성 팩 드롭다운에서 Yuna를 선택합니다. 숫자가 TTS로도 함께 들리지 않게 하려면 Escape로 돌아가 TTS 알림 버튼에서 Enter를 누르고, 사용함 체크 상자에서 Enter를 눌러 체크되지 않음으로 바꿉니다.

- 대상 생명력: 목표 선택 버튼, 하드 대상 버튼, 생명력 모니터 버튼 순서로 들어갑니다. 생명력 모니터는 Retail과 WoW: Forever에는 없습니다.
- 적의 수: 인터페이스 버튼, 전투 버튼, 적 수 알림 버튼 순서로 들어갑니다.


문제가 생기면

- 진행 화면에 "한국어 문구를 추가하지 못했습니다"가 나오면 WowVision은 영어로 동작합니다. 아래 방법으로 로그를 보내 주십시오.
- 진행 화면에 "한국어 음성 팩을 추가하지 못했습니다"가 나오면, 음성 팩을 Yuna로 선택한 알림은 소리가 나지 않을 수 있습니다. 설치 프로그램을 다시 실행해 보고, 그래도 같으면 아래 방법으로 로그를 보내 주십시오.
- 캐릭터 선택 화면의 애드온 목록에서 애드온이 꺼져 있어 WowVision이 로드되지 않으면, 캐릭터가 월드에 들어간 뒤 /enableaddons를 입력합니다. 이 명령은 모든 애드온을 켜고 인터페이스를 다시 불러옵니다.
- 로그 보내기: WowVisionInstaller.exe를 다시 실행해 첫 화면에서 "모든 로그 모으기" 버튼을 실행합니다. 다운로드 폴더에 만들어진 zip 파일을 보내 주십시오.
