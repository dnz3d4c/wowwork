# WowVision 한국어 테스트 빌드 설치 안내

이 묶음에는 파일이 두 개 있습니다.

- `WowVisionInstaller.exe`: 한국어가 추가된 WowVision 설치 프로그램입니다. 원본 설치 프로그램 1.6과 같고, 화면 문구에 한국어만 더했습니다.
- `WowVision-V1.0.0-ko1.zip`: 한국어가 들어간 WowVision 테스트 빌드입니다. 원본 V1.0.0 릴리스와 같고, 한국어 문자열만 더했습니다.

## 먼저 확인할 것

- 게임 클라이언트가 한국어여야 합니다. WowVision은 게임 클라이언트의 언어를 보고 문구 언어를 고릅니다. 클라이언트가 영어이면 한국어 빌드를 설치해도 영어로 나옵니다.
- 설치하는 동안 World of Warcraft를 완전히 종료하십시오.

## 설치

1. `WowVisionInstaller.exe`를 실행합니다. Windows 표시 언어가 한국어이면 처음부터 한국어로 나옵니다. 아니면 구성 요소 화면의 "이 설치 프로그램의 언어"에서 한국어를 고릅니다.
2. 평소처럼 설치합니다. 플레이하는 게임 버전을 체크하고, 버전은 안정판(권장)을 고릅니다. 이 단계에서 원본 WowVision과 필요한 구성 요소(NVDA 음성 브리지, Windows 음성, WoW Login Tool 등)가 설치됩니다.
3. 설치 프로그램을 닫습니다.
4. `WowVision-V1.0.0-ko1.zip`을 플레이하는 게임 버전의 AddOns 폴더에 직접 압축 해제하고, 같은 이름의 파일은 모두 덮어씁니다. 예: Mists of Pandaria는 `C:\Program Files (x86)\World of Warcraft\_classic_\Interface\AddOns`입니다. 여러 버전을 플레이하면 버전마다 한 번씩 압축 해제합니다.
5. 압축 해제 뒤 AddOns 폴더 안의 `WowVision` 폴더에 `WowVision_Mists.toc` 같은 TOC 파일이 바로 들어 있는지 확인합니다. `WowVision` 폴더 안에 `WowVision` 폴더가 또 있으면 안쪽 폴더를 한 단계 위로 옮기고 빈 바깥 폴더를 지웁니다.
6. 게임을 시작합니다.

## 그 뒤에 알아 둘 것

- 설치 프로그램을 다시 실행해도 테스트 빌드는 그대로 남습니다. 화면에 "테스트 빌드 — 설치된 WowVision V1.0.0-ko1 그대로 유지"라고 나옵니다.
- "모두 다시 설치(복구)"를 체크하면 원본 릴리스로 교체되어 한국어가 사라집니다. 그때는 설치 4단계부터 다시 합니다.
- 설치 프로그램이 자체 업데이트를 권하면 "현재 버전으로 계속"을 고르십시오. 업데이트하면 한국어가 없는 원본 설치 프로그램으로 바뀝니다. 설치된 한국어 WowVision에는 영향이 없습니다.
- 새 테스트 빌드를 받으면 설치 4단계부터 다시 합니다.
- 문제가 생기면 설치 프로그램 첫 화면의 "모든 로그 모으기"로 만든 zip 파일을 보내 주십시오. 다운로드 폴더에 저장됩니다.
