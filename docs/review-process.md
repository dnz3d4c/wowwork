# 번역 품질 평가 절차

게임 UI 문자열, 설명서, 설치 프로그램 문자열의 모든 번역은 이 절차를 통과해야 커밋합니다. 번역한 쪽이 "좋다"고 판단하는 것으로는 통과가 아닙니다.

## 원칙

1. **번역자와 평가자를 분리합니다.** 번역한 에이전트는 평가하지 않습니다.
2. **평가자끼리는 서로의 결과를 보지 않습니다.** 앞사람 의견에 끌려가지 않게 하기 위해서입니다. 평가 단계에는 자유 토론(Agent Teams)을 쓰지 않습니다.
3. **판정은 다른 회사 모델이 합니다.** Claude가 지적한 것은 GPT가, GPT가 지적한 것은 Claude가 판정합니다. 같은 모델은 같은 맹점을 공유하기 때문입니다.
4. **평가 구조 자체도 검증합니다.** 일부러 심은 오류를 평가자가 얼마나 잡는지 재서, 기준에 못 미치면 실제 번역에 적용하지 않습니다.

## 단계

| 단계 | 누가 | 무엇을 |
|------|------|--------|
| 0. 기계 검사 | `uv run pytest -q` | 키, 서식 지정자, Lua 문법, 같은 키의 번역 일치, 설명서 구조(제목·표·링크·코드 수). 실패하면 1단계로 넘어가지 않습니다 |
| 1. 번역 | Claude 번역자 1명 | 번역 지침 + 용어표(게임 공식 용어, koKR 번역값) |
| 2. 독립 평가 | Claude N명 + GPT N명 | 관점별로 따로, 서로의 결과를 보지 않고 |
| 3. 반박 | 번역자 | 지적마다 수용(수정안 확정) 또는 반박(근거) |
| 4. 판정 | 지적하지 않은 쪽 회사의 판정자 | 반박된 지적만. 최대 2라운드, 남은 것은 사용자 판단 목록으로 |
| 5. 회귀 확인 | 처음 보는 Claude 1명 + GPT 1명 | 수정된 항목만 다시 평가. 치명·중대 0건이어야 통과. 수정은 최대 2회, 그래도 남으면 사용자에게 넘깁니다 |
| 6. 최종 확인 | 사용자 | UI는 게임에서 직접 듣고, 설명서는 시범 묶음을 읽습니다 |

2단계에서 Claude와 GPT가 같은 항목을 지적하면(범주는 달라도 됨) 반박 없이 수용합니다. 번역자는 지적들을 반영한 최종 번역만 정합니다.

## 평가 관점

| 관점 | 무엇을 잡나 | UI·설치 프로그램 | 설명서 |
|------|-------------|------------------|--------|
| 정확성 | 뜻의 누락·추가·왜곡, `~만`·`~일 때` 같은 한정어와 조건 누락 | O | O |
| 용어 | 게임 공식 용어, koKR 번역값, 파일 간 일관성, 번역 지침의 용어 규칙 | O | O |
| 코드 맥락 | 문자열이 코드에서 어떻게 조립되고 발화되는지(이어 붙이기, 서식 순서, 선택지 라벨) | O | 실제 애드온 동작과 문자열이 설명과 맞는지 |
| 청취 | 스크린리더로 들었을 때 모호한 말과 동음이의어, 길이, 원문에 없는 기호, 문체 규칙 | O | 제목 탐색 구조 |
| 한국어 문장 | 번역투, 문체 일관성, 자연스러움 | 청취에 포함 | O |

평가자 수: UI와 설치 프로그램은 Claude 4명 + GPT 4명, 설명서는 Claude 5명 + GPT 5명입니다.

## 심각도

MQM(번역 품질 평가 업계 표준)의 세 등급을 씁니다.

- **치명**: 사용자가 잘못 행동하게 만드는 오류. 뜻 반전, 잘못된 키·숫자, 서식 지정자 오류, 다른 기능으로 오해하게 하는 용어.
- **중대**: 뜻이 일부 빠지거나 더해진 것, 공식 용어·koKR 값과 다른 용어, 들었을 때 뜻이 갈리는 표현.
- **경미**: 뜻은 맞지만 어색하거나 문체 규칙에서 벗어난 것.

## 평가 구조 검증 (오류 심기)

시범 묶음마다 사본에 오류 10개를 심고 2단계만 돌립니다. 종류는 뜻 반전, 조건 누락, 숫자 변경, 공식 용어 오류, 서식 지정자 순서, 원문에 없는 기호, 동음이의어, 문장 누락, 번역투, 파일 간 불일치입니다. Claude 쪽과 GPT 쪽을 각각 재고, 어느 쪽이든 80% 미만이면 평가 프롬프트를 고친 뒤 다시 잽니다.

## 기록

모든 평가 결과는 `reviews/<날짜>-<대상>/` 아래 JSON으로 남깁니다. 평가자별 지적, 반박, 판정, 회귀 확인이 각각 파일 하나입니다. 이 기록이 번역 이력의 근거입니다.

## 실행

Workflow로 묶음마다 같은 구조를 결정적으로 반복합니다(2026-11-05 사용자 허용). GPT 평가자는 `tools/review/gpt_review.py`가 `codex exec`를 읽기 전용 샌드박스로 실행합니다.
