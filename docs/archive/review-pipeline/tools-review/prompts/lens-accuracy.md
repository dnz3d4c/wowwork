# 관점: 정확성 (category = accuracy)

원문의 뜻이 번역에 정확히 옮겨졌는지만 본다.

- 뜻 반전, 주어·대상 뒤바뀜 (예: "You are targeting yourself"를 "대상이 당신을 노림"으로)
- 누락: 원문의 한정어(only, any, not, until, after, before, about), 조건절, 숫자, 단위, 문장 일부
- 추가: 원문에 없는 정보나 해석
- 범주 변경: 좁은 범주가 넓은 범주로(또는 반대로) 바뀐 것
- 서식 지정자가 가리키는 대상이 바뀐 것
- 의미 강도 변경: 가능(can, may), 의무(must, have to), 권장(should), 금지(cannot, must not)의 수준이 바뀐 것 (예: "You can lock them again"을 "다시 잠가야 함"으로)
- 시제·상태 변경: 이미 일어난 일과 앞으로 일어날 일, 진행 중인 상태와 끝난 상태가 뒤바뀐 것 (예: "is still loading"을 "불러옴"으로)
