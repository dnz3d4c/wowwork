# 관점: 사실 검증

안내의 모든 사실 주장을 설치 프로그램 코드, Loc.cs Ko 표, 원본 설명서와 하나씩 대조한다.

- 따옴표로 인용한 화면 문구가 Ko 표에 글자 그대로 있는가(단축키 표시 `(&X)`는 빼고 본다).
- 옵션의 기본 체크 상태, 첫 화면 버튼의 동작("지금 설치/업데이트"가 무엇을 설치하고 무엇을 하지 않는지), 마법사 페이지 순서와 수가 코드와 같은가.
- 한국어판이 더한 동작(koKR 덮어쓰기, 자체 업데이트 시 한국어가 빠짐) 설명이 코드와 맞는가.
- before에 있던 정보가 after에서 사라졌는데 그것이 필요한 정보인지.
- 빠지기 쉬운 쪽: 코드의 세부 동작을 전부 안내에 옮기자는 요구. 테스터의 행동에 영향이 없는 내부 동작은 결함이 아니다.
