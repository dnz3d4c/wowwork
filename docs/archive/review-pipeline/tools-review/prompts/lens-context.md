# 관점: 코드 맥락 (category = context)

문자열이 실제로 어떻게 쓰이는지 기준으로 본다. `code` 필드를 읽고, 부족하면 `wowvision-ko/WowVision` 아래에서 `L["키"]`를 직접 검색해 주변 코드를 읽는다.

- 다른 문자열이나 숫자와 이어 붙여질 때(예: `number .. " " .. L["dead"]`) 한국어 결과가 성립하는지
- 선택지 라벨, 체크 상자, 설정 이름, 음성 알림, 오류 메시지 등 쓰이는 자리에 맞는 형태인지
- 서식 지정자에 실제로 들어가는 값(이름, 숫자, 방향 등)을 넣어 읽었을 때 자연스럽고 조사 문제가 없는지
- 같은 키가 여러 기능에서 쓰이는데 한 기능에만 맞게 번역된 경우
